Personal Finance Advisor Bot (FinanceAI)

Full-Stack AI Financial Planning, Cash Flow Intelligence, and Interactive Wealth Analytics

1. Executive Summary

The Personal Finance Advisor Bot is a full-stack, enterprise-ready personal finance platform designed to instill financial discipline through intelligent budgeting, automated expense tracking, spending leak detection, and AI financial recommendations.

Engineered using Python, Flask, SQLAlchemy ORM, SQLite, Chart.js, and Google Gemini AI, the system couples mathematical financial modeling (50/30/20 principle) with natural language generative intelligence.

2. Problem Statement & Solution

The Core Problem: Consumers manage multiple cards, subscriptions, and unpredictable expenses. Static spreadsheets lack real-time visual feedback and require manual formula upkeep, leading to abandoned financial plans and zero emergency preparedness.

FinanceAI Solution:

  • Automated AI Budgets: Derives realistic category allowances based on income and historical outlays.
  • Interactive Visualization: 4 Chart.js charts translating raw numbers into intuitive trajectories.
  • Adaptive UX: Clean White Canvas by default with 1-click Dark Glassmorphism switching.
  • Autonomous Fallback: Seamless deterministic rules if API keys are absent or offline.

6. Core Functional Modules

6.1 Authentication & Security

Passwords are securely hashed using Werkzeug's salted PBKDF2 SHA-256 algorithm. Unauthenticated requests are redirected with warning flashes. Every form includes CSRF validation.

6.2 Cash Flow Ledger

Users can log income and expenses with customizable tags, recurring flags, and payment methods (Credit Card, Debit, UPI, Cash).

6.3 Analytics Dashboard

Features 4 high-level KPI cards and 4 interactive Chart.js charts: 6-month Income vs. Expense dual bar chart, category doughnut chart, savings trend line chart, and horizontal budget progress meters.

7. Adaptive Dual-Theme System

Clean White Background (Default): Designed for high readability using slate typography (#0f172a) on an ultra-light canvas (#f8fafc) with subtle elevation shadows.

Dark Glassmorphism: Deep navy canvas (#0a0e1a) with frosted translucent glass cards (backdrop-filter: blur(20px)) and glowing visual accents.

Instant Toggle: The sidebar toggle switches themes with zero flicker by synchronizing with localStorage.

8. Generative AI Financial Engine

The AI Engine operates through two robust modes:

  • Google Gemini AI: Synthesizes verified financial data into personalized category caps, emergency fund guidance, and spending leak audits.
  • Deterministic 50/30/20 Fallback: Automatically takes over if API keys are absent, calculating allocations (50% Needs, 30% Wants, 20% Savings) and a mathematical Financial Health Score.
